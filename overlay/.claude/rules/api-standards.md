# API & Assertion Standards

## API Client Layer — Always Use Typed Clients

Every HTTP call in a test file or conftest fixture MUST go through the module's typed API client fixture.
Never construct URLs manually or call `session.get/post/put/patch` directly.

### Available clients and fixtures

Every client in `api/*_client.py` extends `BaseAPIClient` (`api/base_client.py`).

They are wired to fixtures two ways. Both produce a module-scoped `<module>_api_client`; pick the
one that matches where the tests live.

**1. Explicit, in the module's own `conftest.py`** — used by the deep functional modules:

| Client class | Fixture | Defined in |
|---|---|---|
| `RepoInvoiceClient` | `repo_api_client` | `tests/loss_mitigation/repo_invoice/conftest.py` |
| `AuctionInvoiceClient` | `auction_api_client` | `tests/loss_mitigation/auction_invoice/conftest.py` |
| `ACDClient` | `acd_api_client` | `tests/ancillary/ancillary_cancellation_dashboard/conftest.py` |
| `APDClient` | `apd_api_client` | `tests/ancillary/ancillary_products_dashboard/conftest.py` |
| `UnifiClient` | `unifi_api_client` | `tests/unifi/conftest.py` |
| `PayixClient` | `payix_api_client` | `tests/unifi/conftest.py` |

**2. Generated by the registry in `tests/smoke/conftest.py`** — the smoke suite does not hand-write
a fixture per client. `_client(name, cls)` and `_state(name)` build every client fixture
and state manager:

```python
repo_api_client = _client("repo_api_client", RepoInvoiceClient)
repo_state_manager = _state("repo_state_manager")
```

Add a smoke client by importing it and adding one registry line — not by writing a fixture body.

The tables are examples, not the list: `api/` and the two conftest styles above are the source of
truth.

### Pattern — standard endpoint call

```python
# CORRECT — use the typed client fixture
def test_something(self, repo_api_client, ...):
    response = repo_api_client.approve_invoice(payload)

# WRONG — never construct URLs in tests
def test_something(self, session, base_url, ...):
    endpoint = f"{base_url}{os.getenv('APPROVE_REPO_INVOICE_ENDPOINT')}"
    response = session.put(endpoint, json=payload)
```

### Pattern — endpoint with path parameters (`:param` placeholders)

When an endpoint path contains a `:param` placeholder (e.g. `/records/:application_id`), add a
**typed method** to the client class that accepts the param explicitly. Use `get_path()` internally:

```python
# In api/acd_client.py
def get_general_info_for_loan(self, loan_number: int | str, **kwargs) -> requests.Response:
    return self.get_path("GET_GENERAL_INFO_OF_LOAN__ON_CANC_DETAILS_PAGE_ENDPOINT", {"loan_number": loan_number}, **kwargs)

# In conftest fixture
resp = acd_api_client.get_general_info_for_loan(loan_number)
```

Never call `acd_api_client._url(...)` or `acd_api_client._base_url` directly from conftest or test files —
these are private. Use the typed method instead.

### Pattern — endpoint with appended path segments (`/base/id`)

When additional path segments are appended after the base endpoint path, use `get_with_path()`:

```python
# In api/apd_client.py
def get_product_notes_for_app(self, application_id: int, product_key_name: str, **kwargs) -> requests.Response:
    return self.get_with_path("APD_GET_PRODUCT_NOTES_ENDPOINT", application_id, product_key_name, **kwargs)
```

### Pattern — export/list endpoints with entity-type segments

```python
# In api/apd_client.py
def get_export_activity_list(self, entity_type: str, entity: str, **kwargs) -> requests.Response:
    return self.get_with_path("APD_ACD_COMMON_EXPORT_ACTIVITY_ENDPOINT", entity_type, entity, **kwargs)

# Usage
response = apd_api_client.get_export_activity_list("APD", "administrator", params={"limit": EXPORT_LIMIT})
```

### Pattern — URL needed for a pagination helper

When a helper function needs the raw URL string (e.g. to pass to a paginator), add a `*_url()` method
that uses `url_for()`:

```python
# In api/acd_client.py
def cancellation_loans_by_provider_url(self, type_param: str, username: str) -> str:
    return self.url_for("GET_ANCILLARY_CANCELLATION_LOANS_LINKED_TO_PROVIDER_ENDPOINT", type=type_param, username=username)
```

### Legitimate exceptions (do NOT migrate these)

1. **Pagination link following** — `session.get(next_link)` where `next_link` is a full URL from an
   API response body. Use `client.session.get(next_link)` to reuse the authenticated session.
2. **S3 / PDF download with Okta auth** — these endpoints use `_requests.get(url, headers=okta_bearer_headers)`
   because they require a different auth token, not the basic-auth session.
3. **Hardcoded paths with no env var** — if a path is not in `tests/.env`, use
   `client.base_url` (public property) + `client.session.get(url)`. Add the path to the env if possible.
4. **Multi-endpoint iterator helpers** — helpers that loop over a dynamic list of endpoint templates
   (e.g. `_resolve_cancellation_tracker_ids_by_app`) may use `os.getenv` internally; callers must still
   pass `client.base_url` and `client.session` rather than the raw fixtures.

### Adding a new module

1. Create `api/<module>_client.py` extending `BaseAPIClient`
2. Add one method per endpoint — name it after what it does, not the HTTP verb
3. Wire a module-scoped `<module>_api_client` fixture — either explicitly in the module's own
   `conftest.py`, or, for a smoke module, by adding one `_client(...)` line to the registry in
   `tests/smoke/conftest.py`. Do not hand-write a fixture body in the smoke suite.
4. Never use `session` or `base_url` directly in test files — inject the client fixture instead

### `BaseAPIClient` public interface

```python
client.get(endpoint_env, **kwargs)               # plain GET
client.post(endpoint_env, json, **kwargs)         # plain POST
client.put(endpoint_env, json, **kwargs)          # plain PUT
client.patch(endpoint_env, json, **kwargs)        # plain PATCH
client.delete(endpoint_env, **kwargs)             # plain DELETE
client.get_with_path(endpoint_env, *segments)     # GET + append path segments
client.get_path(endpoint_env, path_params, **kw)  # GET + :param substitution
client.url_for(endpoint_env, **path_params)       # resolve URL string (for paginators)
client.base_url                                   # the API base URL (property)
client.session                                    # the underlying requests.Session (for pagination)
```
